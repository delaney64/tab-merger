# Privacy Policy — Tab Merger

**Last updated: May 2026**

## Overview

Tab Merger is a Chrome extension that merges all open Chrome windows into a single window. This privacy policy explains how the extension handles data.

## Data Collection

Tab Merger does **not** collect, store, transmit, or share any user data. This includes:

- No browsing history
- No tab URLs or titles
- No personal information
- No usage analytics or telemetry

## Permissions

Tab Merger requests the following Chrome permissions:

- **tabs** — Required to read and move tabs between windows during the merge operation.
- **windows** — Required to get all open Chrome windows and consolidate them into one.

These permissions are used exclusively within your browser. No data leaves your device.

## Third Parties

Tab Merger does not integrate with any third-party services, APIs, or analytics platforms.

## Remote Code

Tab Merger does not load or execute any remote code. All extension logic is contained in locally bundled files.

## Changes

If this policy is updated, the updated version will be posted to this page with a revised date.
